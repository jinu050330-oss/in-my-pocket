# In My Pocket v0.1

사람과 사진을 포켓에 담아 다시 보는 모바일 웹 앱입니다. Windows에서 바로 실행해 볼 수 있도록 React와 Vite를 사용했습니다. 휴대폰 브라우저의 사진 선택기를 사용하고, 기록은 브라우저의 IndexedDB에 저장합니다.

## 실행

Node.js 22.12 이상을 사용합니다. Windows PowerShell에서 이 폴더를 연 뒤 실행합니다.

```powershell
npm.cmd ci
npm.cmd run dev -- --port 4173
```

PC에서는 http://localhost:4173 을 엽니다. 휴대폰에서는 PC와 같은 네트워크에 연결한 뒤 Vite가 출력하는 **Network** 주소를 엽니다. 브라우저의 홈 화면 추가 기능은 기기와 제공 방식에 따라 달라집니다. 저장한 사진은 같은 브라우저 프로필의 같은 주소에서 열립니다.

```powershell
npm.cmd run build
npm.cmd run preview -- --port 4174
```

개별 모바일 프레임은 402×874입니다. Figma에 OS 상태바와 홈 표시줄 레이어는 없으며, 앱의 하단 작업 버튼은 브라우저가 제공하는 안전 영역 값을 사용합니다. Figma의 Yuanti SC는 Inter로 대체했습니다. 한국어 화면에는 Nanum Gothic을 적용했습니다. `reference/`에 Figma 내보내기와 이미지 크기·형식·해시를 기록한 `assets.json`이 있습니다. `verification/`에 같은 뷰포트에서 촬영한 앱 캡처가 있습니다. 화면은 독립된 UI 요소로 구성했습니다.

포켓의 기록 수를 누르면 날짜 기록 화면이 열립니다. 하단 오른쪽 버튼은 갤러리로, 탐색 메뉴는 갤러리와 캘린더로 연결합니다. 캘린더 날짜별 목록과 새 사진 처리·미리보기·저장 문구는 데모용으로 정했습니다. 초기 목업의 이름·기록 수는 디자인 표기를 반영했고 연결 데이터가 없는 윤민·진우 포켓의 사진과 목업 날짜에는 임시 연결을 사용했습니다. 541:1242는 온보딩 대안으로 확인했고, 541:1410의 사진 선택 모달 흐름은 포켓의 +에서 기기 사진 선택기를 바로 여는 방식으로 연결했습니다. 로그인과 가입 버튼은 데모 탐색으로 연결됩니다.

## 사진 처리와 저장

`src/segmentation.js`에서 IMG.LY IS-Net 모델을 CPU/WASM으로 실행합니다. 모델과 실행 파일은 첫 실행 시 IMG.LY CDN에서 받아오며 사진은 브라우저에서 처리됩니다. 메모리 사용량을 줄이기 위해 처리본의 긴 변을 최대 2,048px로 제한합니다. 사용자가 선택한 원본 File과 결과 PNG File은 별도 필드로 한 번에 저장합니다. 기기와 브라우저에 따라 디코딩할 수 있는 사진 형식이 다릅니다.

## 확인

Playwright로 Windows Edge의 402×874 뷰포트에서 검증합니다. 앱 주소를 실행한 상태에서 다음 명령을 실행합니다.

```powershell
$env:POCKET_BROWSER_CHANNEL='msedge'
$env:POCKET_URL='http://localhost:4173'
npm.cmd run verify
```

테스트는 카드 스와이프, 기록 및 상세 이동, 갤러리의 345px 스크롤 복원, 캘린더 기록 연결, 사진 선택 취소, 처리 오류의 재시도, 저장 이후 원본 SHA-256 및 PNG 알파 검사를 수행합니다. 모바일 실기기의 사진 선택기와 설치 동작은 검증 범위에 포함되지 않았습니다.
